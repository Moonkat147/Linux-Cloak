# Moonk@t Autostart Cloak v1.47

A KDE/Plasma privacy tool that shadows system autostart entries into your user config
and marks them as `Hidden=true`, letting you silence location services, keyring daemons,
VM agents, and other startup noise without touching system files.

## Usage

```bash
chmod +x moonkat-autostart-cloak.sh
./moonkat-autostart-cloak.sh
